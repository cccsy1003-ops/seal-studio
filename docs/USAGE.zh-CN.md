# 印章2 使用说明

## 启动

双击 `印章2.exe`，无需安装，可离线使用。窗口可以拖动边框自由调整大小，也可以最小化、最大化或关闭。印章预览自动按比例适应窗口；右上角 `—` `□` `×` 分别用于最小化、最大化/还原和关闭。

默认图片位置：程序目录下的 `生成图片` 文件夹（可在界面中修改）。

## 基本流程

1. 输入文字，选择字体。左侧面板可以上下滚动。
2. 选择阳刻（朱文）或阴刻（白文）：
   - 阳刻：文字凸起，纸上是有色的字。
   - 阴刻：文字凹下，纸上是白色的字、有色的底。
3. 选择排字方式，调整列数、字大小、留白、内边距及边框。
   - 传统章法从右列上到下，再往左列。例如“春风得意”先读右边春风，再读左边得意。
   - 横排按从左到右阅读；按输入换行可自行控制每行。
4. 左侧向下滚动到“实际尺寸”，宽和高以厘米（cm）设置。
   - 正方形保持“宽高同步”勾选；长方形取消勾选后分别设置宽、高。
   - 默认 600 DPI；3 × 3 cm 对应 709 × 709 像素。
5. 在预览上方选择反转方式：整章、逐字、指定字或不反转。一般整块刻章选择“整章左右反转”，导入雕刻软件后不要再次镜像。
6. 核对设备的黑白约定。默认“黑色 = 雕刻去除区域”；也可选择“黑色 = 保留凸起区域”。这与水平镜像是两个独立选项。
7. 点击“生成并保存到 D 盘”（保存位置可改）。每次建立一个独立文件夹，避免覆盖旧作品。
8. 点击“打开输出文件夹”。雕刻请使用名称以“雕刻图”开头的图片。

## 导出内容

- **雕刻图 PNG**：纯黑白、无透明背景，保留 DPI 信息。
- **可选 BMP**：兼容旧雕刻软件。
- **盖印效果 PNG**：红白配色、模拟整块盖印后的实际方向，只供参考，不用于雕刻。
- **尺寸与使用说明.txt**：记录字体、尺寸、像素、DPI、镜像和黑色含义。

## 字体

- 自动读取本机可用字体，包含楷体、隶书、华文行楷等系统字体。
- 不同电脑的字体数量不同。本软件没有捆绑“全部印章字体”或收费字体包。
- 可内置崇羲篆体和王汉宗印篆体繁，详见 `docs/FONTS.md`；其他篆刻风格需要相应字库；在“导入字体”中选择合法取得的 TTF / OTF / TTC 文件。
- 导入只复制到软件的 `Fonts` 文件夹，不需要安装进 Windows。
- 也可以把字体放入程序目录的 `Fonts` 文件夹，再点击“刷新字体”。
- 字体缺少输入字符时，会提示缺字并禁止导出，避免自动换字体导致错误。
- 部分特殊编码篆字库未映射到常规汉字，不能通过普通汉字输入直接使用。
- 支持“简 → 繁”和撤销转换，转换后请核对多义字；不替代篆字考证。

## 尺寸与设备

- 宽、高范围 0.3～20 cm，DPI 范围 150～1200。
- 为保证稳定，单张最多 1600 万像素、单边不超过 8000 像素；超出会提示调整。
- 如果雕刻软件忽略 PNG 的 DPI，请导入后手动设置实际厘米尺寸。
- 本软件生成位图图片，不生成刀路、激光功率或雕刻深度。
- “盖印效果”显示实际盖印方向；逐字反转与整章反转的左右列位置不同，详见下文。

## 反转方式

反转方式在右侧预览上方选择。

1. **整章左右反转**：整个印面的字形和左右位置一起翻转。一般整块刻章使用此项，盖印后与输入排版一致。
2. **每个字单独左右反转**：每个字在原来的位置左右翻转，排列顺序不变。若整块盖印，字形正常但左右列会交换。
3. **只反转指定字**：选择后勾选下方显示的某一个字或几个字，只有勾选的字原位翻转。序号按输入顺序，不计空格与换行。修改文字后需重新勾选。
4. **不反转**：雕刻图保持输入方向；整块盖到纸上会左右反转。

左侧“盖印效果”模拟整块印章实际盖到纸上的方向。右侧“雕刻图”是导出文件的方向。反转均为水平方向的左右镜像，与黑白反相相互独立。

文件名和尺寸说明会记录所选反转方式，指定字的序号会写进尺寸说明。切换汉白文/小篆朱文时保留所选反转方式。程序会记住上次所选方式及勾选字。旧版镜像开启会自动对应整章左右反转。

## 设置保存

程序会记住上次参数，保存在程序目录的 `设置.xml`。
