本仓库不附带任何第三方字体文件。程序可以读取系统字体，也可以从程序目录的 `Fonts` 文件夹加载字体。以下字体为项目开发与示例中使用过的篆刻风格字库，请自行从官方/原始来源获取，并遵守各自的许可。

## 使用建议

1. 从上述官方渠道下载字体文件（`.ttf` / `.otf` / `.ttc`）。
2. 在软件中点击“＋ 导入字体”，选择字体文件；程序会复制到程序目录的 `Fonts` 文件夹。
3. 点击“刷新字体”，在字体列表中选择导入的字体。
4. 篆体多支持繁体字；输入简体后可点击“简 → 繁”，并核对姓名与一简多繁字。
